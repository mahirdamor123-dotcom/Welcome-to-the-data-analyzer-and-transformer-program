# 📊 Data Analyzer and Transformer Program

A simple Python console application that allows users to input numerical data and perform various data analysis operations. This project demonstrates the use of core Python concepts such as functions, recursion, lambda functions, sorting, and returning multiple values.

---

## 🚀 Features

* ✅ Input a 1D dataset
* ✅ Display dataset summary using Python built-in functions
* ✅ Calculate the factorial of a number using recursion
* ✅ Filter data based on a threshold using a lambda function
* ✅ Sort data in ascending or descending order
* ✅ Display dataset statistics (minimum, maximum, total, and average)
* ✅ Menu-driven interface for easy interaction

---

## 🛠️ Concepts Used

This project demonstrates the following Python concepts:
